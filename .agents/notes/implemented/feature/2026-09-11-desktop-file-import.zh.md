# Agent Note: 原生文件与文件夹导入

Status: implemented

[English](2026-09-11-desktop-file-import.md) | 中文

## Decision

桌面端将用户明确选中的本机文档和目录复制为持久副本，将保存路径加入原始 composer。引用经普通用户文本记录入日志，不引入未记录的模型上下文。导入保留原始字节和目录结构，不依赖 MIME 检测或文档转换。

导入器拥有独立批次目录，全部成功后才发布结果；失败清理本批次。原文件保持不变，同名文件拥有独立父目录，符号链接和包含附件存储的导入明确失败。IPC 仅允许经过认证的原生主 frame。导入期间锁定原始 composer，切换会话不会将结果加入其他草稿。

按用户要求，桌面载体移除原生草稿检查点暴露，使用原版浏览器草稿持久化。既有检查点文件不删除，不再承诺跨 origin 恢复。更新安装仍需 Host 保存与退出校验。内部草稿锁保护保留，用于附件导入等明确事务。

## Alternatives

回移新版上游通用上传服务需要单独的跨包迁移。本次针对原生 DMG 与 EXE，复制本机资料并记录引用，不引入另一套远程上传协议。纯浏览器部署仍接收图片。导入不执行 Word 正文提取。

## Verification

单元测试覆盖中文嵌套名称、字节保留、空目录、同名文件、链接拒绝和失败批次。真实 Loader 浏览器测试通过明确的测试原生传输使用真实磁盘复制。用户提供的 47 文件目录已复制到隔离临时目录，所有相对路径及 SHA-256 均一致，未修改原件。平台安装包仍需各自的原生构建和冒烟结果。

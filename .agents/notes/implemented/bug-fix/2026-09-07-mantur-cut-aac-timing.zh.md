# Agent Note: 保持漫途 Cut 导出的 AAC 时序

Status: implemented

[English](2026-09-07-mantur-cut-aac-timing.md) | 中文

## Problem

Remotion 4.0.509 的普通单次 H.264 导出先将 AAC 编入 ADTS，再把音频复制进 MP4。中间格式丢失编码器预填充信息。原软件及 VideoToolbox 路径的合成脉冲在 48 kHz 下延后 2048 个采样，约 42.67 毫秒。编辑器预览和已保存时间轴不包含该延迟。

## Decision

受控[漫途 Cut 补丁](../../../../packages/client/ui-mantur-editing/adapters/mantur-cut.patch)修改编辑器普通、非 muted 的 H.264/AAC 渲染路径。Remotion 公开参数将现有 PCM16 混音分离到 WAV。现有视频引擎选择及重试结束后，配置的 FFmpeg 直接在最终 MP4 中执行一次原生 AAC 编码，并复制视频流。FFprobe 读取已渲染 WAV 的采样率；最终 MP4 的 movie timescale 使用该采样率，保留包括单帧导出在内的采样级音频时长。不通过移动轨道补偿预填充。

辅助函数在渲染视频前检查 Remotion 4.0.509、已解析的媒体程序及原生 AAC 支持。不支持的自定义程序明确失败；音频收尾从不切换编码器或重跑视频。显式静音、自定义 direct-hardware MP3 处理、分离音频请求及其他编码格式保留原路径。原生 VideoToolbox 使用普通收尾流程。

每次导出在目标位置旁拥有独立临时目录。辅助函数在其中渲染视频与 WAV、编码最终 MP4、检查并同步文件、重命名到请求的目标，再清理私有文件。取消与超时终止自有媒体进程，并等待其关闭后再清理。I/O、编码、取消和清理错误仍是失败；清理失败保留主要错误。导出任务在 AAC 运行时报告收尾阶段，并保留失败阶段与清理元数据。原有结果发布只在该操作成功返回后执行。

补丁修改编辑器的渲染编排及服务端导出调用方，不修改 Harness 核心、Agent loop、MCP 协议、已安装依赖或锁定版本。源码提交、结果树和补丁摘要记录在[剪辑包 README](../../../../packages/client/ui-mantur-editing/README.zh.md#understand-the-implementation)。

## Fixed audio presence semantics

Remotion 4.0.509 为每个成功渲染的帧记录素材容器，包括空容器。其音频存在判定检查非空的帧容器数组。因此，合法、普通、非 muted 的 H.264 渲染即使只有画面、静音或零音量素材，也会生成音频。PCM 分离保留该既有行为。编辑器拒绝空帧范围；成功合成至少处理一帧。显式静音保留原有仅视频路径，因为在那里请求分离音频会失败。

纯画面导出含多余静音轨仍是既有依赖缺陷。本次既不修复该缺陷，也不承诺精确保留零音量素材的源音轨身份。依赖行为改变时，版本检查和已记录输出回归要求重新评估；它们从不强制生成静音轨来掩盖不兼容升级。

## Alternatives considered

**移动固定时长的音频。** 预填充取决于编码器和采样率。减去约 43 毫秒会掩盖容器缺陷，无法保留所有范围或采样率。

**继续将 AAC 保存在 ADTS 中直到最后封装。** 流复制无法恢复丢弃的预填充元数据。重新引入 ADTS 的负对照在原生 AAC 下偏移 1024 个采样，脉冲检查失败。

**修改或升级 Remotion。** 本次使用已有公开 PCM 分离 API，不改动安装的 4.0.509 包。纠正依赖的音频存在语义是独立工作，会产生不同的输出后果。

## Verification

在打过补丁的编辑器中，`npm run verify:audio-finalization` 运行进程失败检查和真实 Remotion 渲染，要求显式提供 `CC_BROWSER_EXECUTABLE`，从不下载浏览器。所属目录的预期 JSON 记录流时长、脉冲偏移和编码器结果。矩阵覆盖 32/48 kHz、24/30 fps、完整及非零范围、混音与重采样、头尾脉冲、最短单帧、静音、纯画面、零音量和显式静音。macOS 额外要求 VideoToolbox 成功渲染，以及注入的最终音频失败仅渲染一次视频。成功收尾保留视频包哈希、PTS、DTS 和包时长。

失败检查覆盖 AAC 支持缺失、渲染、WAV 缺失、编码、重命名、清理、取消与超时。取消和超时断言确认 promise 结束前子进程 PID 已退出。独立并发运行使用私有目录。TypeScript 检查及已有视频引擎、自定义硬件、导出暂存和导出运行时检查覆盖相邻行为。Windows 失败用例因程序与权限控制依赖 POSIX 而明确待测；Windows 渲染及非 Mac 硬件仍未验证。

## Consequences

最终封装保留编码器延迟元数据和采样级时长，代价是磁盘上额外的 WAV、临时视频及 MP4、一次最终封装进程，以及配置的原生 AAC 能力要求。收尾完成前不能使用结果。发布后的清理失败仍会拒绝任务，并由原有输出清理移除已发布文件。合成回归不修改此前成功导出的剧集成片或活动用户编辑器。

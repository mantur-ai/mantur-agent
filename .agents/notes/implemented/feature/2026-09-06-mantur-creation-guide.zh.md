# Agent Note: 漫途创作模式与助手引导

Status: implemented

[English](2026-09-06-mantur-creation-guide.md) | 中文

## Problem

漫剧创作者需要按剧本、制作、剪辑和素材组织的入口。快捷操作应帮助编写当前请求，而不是替换已有草稿，或暗中改变 Agent 身份、模型与权限。

## Decision

漫途导航插件占用两个通用对话 slot：标题下方的创作选择和常驻输入框上方的上下文引导。Host 设置持久化最近模式与明确关闭的选择。模式选择只改变目录推荐筛选和本地化引导文案，不选择 Agent 预设，也不添加模型上下文。

产品组合提供有序的真实广场 slug。浏览器将列表与当前 Host 目录取交集，匹配技能缺失时保留较少推荐。目录失败保持可见并提供重试。快捷插入通过 Session input facade 追加带标题的引用，按 source/ref 标识去重，从不提交。安装必须成功后才能插入，切换会话会使待执行插入失效。广场“使用”保持[广场决策](2026-09-03-mantur-marketplace-navigation.zh.md)中的独立新建会话行为。

馒头仔在快捷入口上方独占布局空间的气泡中展示固定文案，不覆盖可编辑内容。关闭选择持久化，切换模式不强制展开气泡。首条消息收起欢迎区域。[漫途品牌标识](2026-09-02-mantur-brand-identity.zh.md)保持不变，助手不替代产品 logo。

## Alternatives considered

**将模式作为 Agent 预设。** 预设选择可以改变工具、身份和模型可见上下文。用户要求的导航选择没有授权这些变化。

**快捷入口复用广场“使用”。** 该操作会新建会话。向当前输入框插入引用可以保留用户草稿与附件。

**编造能力名称以填满每一行。** 目录不包含四个独立的剧本技能。配置中的真实 ID 与实时元数据取交集，确保可用性和名称真实。

## Consequences

共享对话增加放置 slot 和一个追加引用操作，产品文案与推荐规则留在漫途插件。偏好使用既有 Host 设置传输。对话在广场页面后方仍保持挂载，因此引导详情有独立的打开状态。定向测试覆盖关闭记忆、延迟安装完成、草稿保留与重复插入；构建后的浏览器预期检查真实 Loader、Remote、输入框及窄窗口布局。引导文案与模式变化均不消耗模型 token。

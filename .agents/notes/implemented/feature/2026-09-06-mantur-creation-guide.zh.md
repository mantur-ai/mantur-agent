# Agent Note: 漫途创作模式与助手引导

Status: implemented

[English](2026-09-06-mantur-creation-guide.md) | 中文

## Problem

漫剧创作者需要按剧本、制作、剪辑和素材组织的入口。快捷操作应帮助编写当前请求，而不是替换已有草稿，或暗中改变 Agent 身份、模型与权限。

## Decision

漫途导航插件占用三个通用对话 slot：标题下方的创作选择、常驻输入框上方的上下文引导，以及所有者创建的标题、工作区与内容节点的排布。Host 设置持久化最近模式与明确关闭的选择。模式选择只改变目录推荐筛选和本地化引导文案，不选择 Agent 预设，也不添加模型上下文。

漫途把现有工作区选择器放在紧贴输入卡下方、左对齐的页脚。在编辑器之后渲染同一控件，让视觉与键盘顺序一致，而不复制工作区状态或草稿转移逻辑。hero 收起时内容节点保持相同的 React 位置；官方组合保留工作区在编辑器之前的顺序。

产品组合提供有序的真实广场 slug。浏览器将列表与当前 Host 目录取交集，匹配技能缺失时保留较少推荐。目录失败保持可见并提供重试。快捷插入通过 Session input facade 追加带标题的引用，按 source/ref 标识去重，从不提交。安装必须成功后才能插入，切换会话会使待执行插入失效。广场“使用”保持[广场决策](2026-09-03-mantur-marketplace-navigation.zh.md)中的独立新建会话行为。

推荐按钮使用人工维护的本地化短名，中文不超过四个汉字。悬停提示、详情和插入引用保留目录完整名称；缺少映射时显示明确的配置警告。短名不改变技能 ID 或模型可见引用。

馒头仔通过锚定角色右上方的固定定位气泡展示固定文案。气泡不占布局行，因此可见性和文案变化不会移动推荐行或输入框。模式标签下方空隙不足时，若标签旁边能提供至少 180px 的阅读宽度，气泡会使用该空间；更窄的窗口仍将可滚动正文放在标签下方。这避免了桌面最小尺寸 880×600 下正文不足一行的问题，不改变字号、输入框布局或角色上方的间距。关闭按钮位于滚动区域之外。关闭选择持久化，切换模式不强制展开气泡。首条消息收起欢迎区域。[漫途品牌标识](2026-09-02-mantur-brand-identity.zh.md)保持不变，助手不替代产品 logo。

视口宽度小于 820px 时，首页推荐行无论引导展开或关闭都额外预留 40px。右侧空间不足以放置气泡时，这段高度保证标签下方的正文可读，也覆盖带自动项目页脚的未关联编辑器。引导交互不能改变预留高度或字号。吉祥物按钮止于输入框边框，超出的装饰图片不会拦截输入区点击。

## Alternatives considered

**将模式作为 Agent 预设。** 预设选择可以改变工具、身份和模型可见上下文。用户要求的导航选择没有授权这些变化。

**快捷入口复用广场“使用”。** 该操作会新建会话。向当前输入框插入引用可以保留用户草稿与附件。

**编造能力名称以填满每一行。** 目录不包含四个独立的剧本技能。配置中的真实 ID 与实时元数据取交集，确保可用性和名称真实。

## Consequences

共享对话增加放置 slot 和一个追加引用操作，产品文案与推荐规则留在漫途插件。偏好使用既有 Host 设置传输。对话在广场页面后方仍保持挂载，因此引导详情有独立的打开状态。定向测试覆盖关闭记忆、延迟安装完成、草稿保留与重复插入；构建后的浏览器预期检查真实 Loader、Remote、输入框及窄窗口布局。引导文案与模式变化均不消耗模型 token。

工作区切换通过对话所有者转移完整编辑器文档、引用 occurrence 和图片。[自动项目决策](2026-09-06-mantur-automatic-project.zh.md)拥有从未关联编辑器发起的持久转移，包括取消与重试行为。

每个 Web 构建都包含已确认的 2x/3x 透明吉祥物，因为分发的漫途 overlay 可以在通用前端上加载其 UI 插件。现有模式设置选择四张扒边图，不引入第二份模式状态。固定 184×120 画布的 y=104 接触线对齐输入框边框；对话小助手与原生账号的已有插图位使用方形招手图，不将扒边姿势挤入方框。原素材保留归档，运行时不为缺失资源替换其他图。组件测试固定素材映射；构建后浏览器检查覆盖图片解码、接触位置、模式持久化与草稿保留。文档元数据、favicon 和安装 manifest 的品牌仍由构建 profile 所有。

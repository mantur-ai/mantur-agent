# Agent Note: 验证 Mantur 失败与回调生命周期

Status: implemented

[English](2026-10-24-mantur-coverage-gaps.md) | 中文

## Problem

导航、工作台和技能市场测试遗漏了逐文件覆盖率要求包含的回调生命周期及失败路径。Python 运行时的进程身份读取器在 macOS 上也未测试 Linux 文件系统路径。行为测试通过本身不能证明达到逐文件覆盖率要求。

## Decision

导航测试结算已被替换的目录请求、重试失败读取、操作已安装技能导航和已发布 schema 变体，并观察 Remote 刷新及草稿失败处理。工作台测试控制原生视图 Promise 和延迟会话通知，断言过期操作不能打开视图或覆盖当前状态。注册测试观察订阅移除。这些测试保留实际实现和已有断言。

技能市场测试创建真实归档及私有版本目录，验证缓存身份、清单排序、元数据限制、回退校验、调用者取消和发布冲突。范围受限的文件系统故障注入提供普通跨平台文件系统样例无法稳定产生的错误。竞争发布的版本包含真实复制的字节，由正常校验器检查。清单测试检查实际排序比较器的自反性和反对称性，再交给原生排序，并验证发布后的路径顺序和字节。删除相等结果的负对照会令该测试失败。缓存目录检查先判断首项缺失，再判断项目数量；空目录和多项目录仍以相同诊断拒绝。

Python 进程身份测试提供命令名含空格和括号的 Linux stat 记录，以及进程条目缺失情形。测试只拦截样例的精确 proc 路径，并在每个用例后恢复主机平台属性描述符。已有真实进程测试继续承担主机集成证据。不需要修改运行时行为、覆盖率阈值、排除项或超时。

## Alternatives considered

**把汇总测试通过当作覆盖率通过。** 门禁要求每个被测文件达到百分之百；测试通过数量不能替代该结果。

**增加跳过、覆盖率忽略或弱化断言。** 这些做法会隐藏未测试路径，而非检查其可观察效果。

**依赖延迟安排回调竞态。** 显式 Promise 结算和通知投递可以复现相关顺序，无需依赖调度速度。

**要求在 Linux 上才能测试进程身份解析。** 可移植 proc 样例在受支持的测试主机上验证解析和读取失败，同时保留独立的真实 Linux 集成测试。

## Consequences

新增测试覆盖已有行为，不改变模型可见输出，也不需要新增录制会话数据。临时资源和全局覆盖均有明确清理。定向覆盖率用于定位剩余遗漏；完成任务仍须通过未改变的全仓门禁。覆盖率通过不代表另行跟踪的 HMR 或发布验收问题已经解决。

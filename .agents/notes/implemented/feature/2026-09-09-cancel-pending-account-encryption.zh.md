# Agent Note: 取消等待中的账号加密

Status: implemented

[English](2026-09-09-cancel-pending-account-encryption.md) | 中文

## Problem

首次网页登录在创建授权尝试前等待操作系统加密。暂时跳过会中止登录，但仍等待其前台操作，因此加密调用不返回时，登录和暂时跳过都会保持忙碌。

## Decision

桌面控制器允许取消对首次加密写入的等待。存储层继续跟踪底层操作，供关闭流程等待，并在加密前及 SQLite 提交前检查取消状态。取消会释放回调监听器和前台状态，不接受迟到的加密结果。加密提交成功之前不会发起服务器请求。

## Alternatives considered

在持久化之前打开网页会削弱响应丢失后的恢复能力。仅通过超时清除忙碌状态，会让原登录仍有机会继续。取消调用方的等待并保留存储层对操作的管理，同时保持显式取消和持久化请求顺序。

## Consequences

首次写入加密期间可以完成暂时跳过。已有账号清理及关闭仍等待各自管理的操作；此变更不会关闭系统对话框，也不能确定已报告的打包客户端故障原因。受控测试覆盖迟到的加密成功和拒绝、初始化和解密拒绝，以及失败后的重试。组装界面回放覆盖登录准备未完成时返回未发送草稿。真实操作系统与网站验收仍需单独完成。

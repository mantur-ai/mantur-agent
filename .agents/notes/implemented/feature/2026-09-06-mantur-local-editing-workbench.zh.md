# Agent Note: 从漫途打开本地剪辑工作台

Status: implemented

[English](2026-09-06-mantur-local-editing-workbench.md) | 中文

## Problem

漫途首页选择剪辑后，需要在对话旁打开完整时间线编辑器。详情栏限定于 Session 且宽度适合工具查看；`main.page` 会隐藏对话。现有两个位置都无法表达这个布局。

## Decision

在 `ui-layout` 中新增通用根插槽 `main.workbench` 和临时打开/关闭动作，保持对话在组件树中的位置稳定。可选的 `ui-mantur-editing` 插件提供本地编辑器嵌入、本地化控件，以及通过 Host 设置传入并校验的地址。漫途 bundle 包含默认禁用的配置行，部署方必须显式提供已运行的编辑器地址。不修改 agent-loop，也不复制编辑器实现。

导航仅在设置接受用户明确选择后发出类型化的 `mantur/creation-mode-selected` 事件。重复选择仍通知；设置恢复和保存失败不通知。剪辑模式打开工作台，其他模式关闭工作台；卸载插件会释放监听和内嵌页面。模式按钮按对话栏宽度适配。素材、工程保存、提案审核和导出仍由上游编辑器负责。

隔离实验通过 profile 补丁挂载已有 `dsh-mcp-client`，连接 OpenChatCut 0.2.14，提交为 `19cba6e1a70a3e589545ce02de975f6494c918f6`。Bearer 凭据仅保留在 Host。这是单工程传输实验；展示插件不实现生产级会话与工程绑定，也不打包编辑器进程。

## Alternatives considered

现有详情插槽过窄且首页不可用；主页面会隐藏对话。复制编辑器状态会重复维护持久化和撤销逻辑。通用工作台插槽让这些职责保留在现有实现中。

## Verification

定向组件与组合测试覆盖尚无 Session 时打开、保持对话节点、收起重开、重复选择、写入失败、无效地址、双语快照和卸载。真实 `dsh --profile mantur` 组合可从首页剪辑标签打开已保存的编辑器工程。

真实编辑器导入了三段本地合成 MP4。公开 MCP 暂存三次裁剪和一次重排；在界面手动确认后应用四项操作。时间线从九秒变为六秒，单次撤销/重做可回退/恢复整批修改。在漫途中重新打开工程恢复了六秒时间线。浏览器导出生成 1920×1080 的 180 帧 H.264；完整解码及第 1、3、5 秒采样确认顺序为 C、A、B。未发起模型请求。

## Upgrade check

上游更新后，重新运行布局、导航和剪辑包测试、Client 构建，以及浏览器首页模式打开/关闭流程。验证真实编辑器仍支持 iframe 中的工程地址、保存素材恢复、公开 MCP 草稿审核和可解码文件导出。支持多会话前重新检查工程所有权和传输版本错误。

## Consequences

编辑器必须预先运行在回环 HTTP 地址。AGPL、Remotion、字体授权、原生二进制安装以及 Windows/macOS Intel 打包仍属于分发工作。该实验不代表已支持多工程模型工作流，也不代表商用嵌入授权已明确。

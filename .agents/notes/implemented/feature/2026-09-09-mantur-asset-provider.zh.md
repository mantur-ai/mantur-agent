# Agent Note：受版本保护的资产服务

Status: implemented

[English](2026-09-09-mantur-asset-provider.md) | 中文

## 问题

提示词提案准备完成后，流水线报告可能发生变化。报告替换与历史记录完成是独立写入，中断可能导致两者不一致。

## 决策

漫途资产服务读取用户选择的流水线报告，将提示词草稿、提案、实际请求字段与媒体绑定分开保存。源更新使用请求捕获的文件系统版本与源指纹。替换前先提交日志，历史记录保留所选提示词字段以便受保护的恢复。服务不调度生成，也不推断缺失的图片绑定。

恢复使用已有待处理日志，因为报告替换与历史完成是独立写入。替换或完成失败时，提案保持未完成。条件日志写入在替换前锁定观察到的版本，并为完成步骤保留该版本，避免静默覆盖并发更新。测试在两次写入处注入失败，拒绝源文件外部编辑后的恢复，并同步两个初次日志写入者。覆盖同一 LocalFileSystem 实例和重新打开的 Session 对象，未覆盖进程重启或跨进程排他。

## 考虑过的替代方案

根据文件名推断媒体绑定会把候选观察结果当作已确认的生成结果。候选发现仅供审核，报告替换必须匹配捕获的源版本与指纹。

提案工具在检查请求归属与源指纹前验证 JSON 编辑字段；额外媒体字段和格式错误的提示词值会在写日志前被拒绝。

## 影响

面板预览经文件签名验证的项目内图片和视频。恢复仍由 Host 执行；跨进程排他和断电持久性尚未验证。

## 验证

失败注入覆盖报告替换、历史完成、外部源编辑和并发初次日志写入。可移植的 Host 测试在私有临时目录中创建三表合成报告和仅含签名的媒体测试文件，验证文件服务与身份检查，不验证媒体解码或远程视频可用性。

恢复操作会在占用日志版本和替换源文件之前拒绝缺失或状态不一致的待完成提案。回归用例将持久化提案状态改为 requested，验证拒绝恢复后源文件字节保持原样。

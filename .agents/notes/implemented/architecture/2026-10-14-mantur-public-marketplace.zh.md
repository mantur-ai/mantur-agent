# Agent Note: Mantur 公开广场网关

Status: implemented

[English](2026-10-14-mantur-public-marketplace.md) | 中文

## 问题

桌面广场请求了已停用的 `/api/v1/skills` 和 `/api/v1/recipes`，正式环境返回 HTTP 404。公开目录已迁移到分页网关，元数据字段不同，Skill 安装包可匿名下载。

Host 保留网关的输入要求和有序步骤。客户端展示输入说明、必填项、可选值、默认值和步骤说明；空输入要求和空步骤不展示。步骤不会替代缺失的复刻说明。

## 决策

漫途广场插件使用 `/api/public/agent/v1` 获取 Skill、配方目录和详情以及 Skill 安装包。插件校验成功网关封装，读取全部 Skill 分页，拒绝不一致的分页和重复编码，并保留原有的受限解压与原子安装。公开下载不携带凭据。不修改上游核心文件。

配方投影把缺失价格、作者、算子编码和复刻次数保留为 null。样片类型接受线上实际存在的大小写形式。发布时间保留原有时区信息，也允许没有时区。已发布的 `usage` 提供复刻说明；没有说明时仍可预览，但 UI 和状态层均拒绝启动。不根据样片编造说明、模型名或价格。

## 考虑过的替代方案

**仅替换接口前缀。** 分页、字段名和下载接口均已变化，只换前缀不能恢复列表与安装。

**补写缺失的配方说明。** 样片不能确定可复现参数，也不构成算子调用授权。缺失说明时明确显示不可启动。

## 影响

插件可以浏览正式目录并在不发送凭据的情况下安装公开 Skill。桌面展示仍保留安装前显式登录流程。没有制作说明的配方只能预览。可选真实接口测试读取正式目录并把真实包安装到临时目录，不进行付费操作。本变更不代表 Windows 生产线执行已通过；独立 Node 的查找以及内置 Skill 的 Electron 子进程环境仍属于单独的排查事项。

# Agent Note: 保留离线编辑检查点的原始文档

Status: implemented

[English](2026-10-24-mantur-cut-offline-checkpoint.md) | 中文

## Problem

离线编辑检查点同时包含原始工程和可编辑草稿。重建持久化字段时遗漏原始文档会丢失草稿基准的独立证据，即使版本匹配的工程存储仍允许常规恢复。

## Decision

受维护的 [Cut 退出补丁](../../../../packages/client/ui-mantur-editing/adapters/mantur-cut-shutdown.patch)通过既有工程迁移校验传入的 `baseDoc`，要求规范化后的版本摘要等于检查点基准版本，并在保存与加载时保留该文档。空值、畸形或版本不匹配的原始文档会使检查点无效。旧 v1 检查点仍可省略原始文档；此时恢复使用版本匹配的已保存工程。新的检查点不能覆盖无效的已持久化检查点。

[桌面源码配置](../../../../apps/desktop/mantur-cut/source.json)固定补丁摘要和结果树。此适配器修改不需要更改 Harness 核心。[持久化保存基准决策](2026-10-24-mantur-cut-persisted-save-base.zh.md)独立约束浏览器重连所有权与已确认版本；本决策不取代它。

## Alternatives considered

**删除 producer 的原始文档。** 这会掩盖序列化丢失，并移除所有新检查点中的恢复证据。

**接受未校验的原始文档或替换其版本。** 这允许检查点宣称的原始文档与其声明的编辑基准不同。

**要求所有 v1 检查点都包含原始文档。** 可选字段已经允许旧检查点省略它。已保存工程仍匹配基准版本时，无须拒绝这些文件。

## Consequences

检查点在草稿之外保留规范化后的原始文档。工程迁移继续负责校验和规范化，因此版本比较使用迁移后的文档。损坏的证据留在磁盘上供明确恢复，不会被静默丢弃。

生产契约验证命令包含真实文件往返与新进程恢复检查、迁移规范化、省略原始文档，以及保存和加载时拒绝无效原始文档。既有离线存储所有权断言仍须通过。录制会话与包内 GUI 验收仍是独立的发版要求；源码测试不能证明这些要求已满足。

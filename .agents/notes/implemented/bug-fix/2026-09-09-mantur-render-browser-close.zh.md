# Agent Note: 确认渲染浏览器进程与管道关闭

Status: implemented

[English](2026-09-09-mantur-render-browser-close.md) | 中文

## 问题

内嵌编辑器一旦获取过渲染浏览器就拒绝安装准备。固定版本渲染器的公开关闭操作等待进程退出，但不公开输出管道关闭后触发的子进程 close 事件。因此，视频导出成功不代表完整关停。

## 决策

编辑器的安装期补丁校验 CommonJS BrowserRunner 与 ESM 渲染器 bundle 已审核的原始和补丁后 SHA-256。在 spawn 后、异步浏览器初始化前订阅 close 事件，并在该 runner 上公开对应 Promise。未知依赖字节会拒绝安装。修改前校验两个模块入口，保留原有许可声明。

编辑器为每个浏览器保留唯一清理 Promise，同时等待公开关闭操作和已记录的进程及管道关闭。只有两者完成才减少待关闭浏览器计数。缺失证据、关闭未完成或清理失败仍阻止安装。渲染与清理错误分别保留。不引入进程全局 spawn 拦截、PID 轮询、超时视为成功或签名策略变更。

媒体子进程失败保留现有拒绝行为，诊断包含操作标签、可执行文件名和 PID，不增加参数、凭据值或完整路径。先前隔离导出中尚未解释的 SIGKILL 仍作为失败保留，即使后一次导出和关停成功。

## 验证

补丁校验覆盖两个模块入口、已知源码的幂等处理和未知源码拒绝。受控关闭屏障证明，浏览器关闭操作先于进程及管道 Promise 完成时，关停不能提前完成。测试保留缺证据拒绝和同时发生的渲染、清理失败。真实浏览器探针与隔离原生编辑器导出验证依赖补丁；最终签名候选验收仍单独执行。

## 曾考虑的替代方案

只信任公开浏览器关闭操作无法观察进程及管道是否完成关闭。删除待关闭浏览器检查会报告缺乏依据的关停成功。进程全局 spawn 包装会影响无关生产者。固定版本依赖补丁在实际拥有者处公开缺失的观察结果，不改变这些策略。

## 后果

依赖仍固定于已审核的渲染器版本。版本或源码变化需要重新审核并更新两个字节标识。源码记录包括安装期补丁、验证和编辑器关停实现。一次诊断导出通过不能证明先前原因不明的进程终止已消除。

# 原生账号取消

[English](README.md) | 中文

首次授权会先加密保存请求，再联系签发方。暂时跳过会取消调用方对首次写入的等待，无需等待系统加密返回。存储层继续跟踪已接受的系统操作，供关闭流程等待，并在加密前及提交结果前检查取消状态。迟到的结果不能创建账号记录或发起登录请求。

此行为不会中断操作系统授权对话框，也不会让关闭流程跳过已接受的存储操作。已有授权尝试和凭据的清理仍等待对应的取消或撤销处理。参见[决策](../../../../.agents/notes/implemented/feature/2026-09-09-cancel-pending-account-encryption.zh.md)。

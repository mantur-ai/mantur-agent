# Agent Note：漫途启动登录

Status: implemented

[English](2026-10-14-mantur-startup-login.md) | 中文

## 问题

原生账号插件提供设置页和按需弹窗，但未登录的新安装直接进入对话页。用户发送消息时可能先遇到无关的模型凭据缺失错误，看不到账号配置入口。

## 决策

根级遮罩在启动时订阅既有 Main 账号客户端。检查中和登录失败时保留登录页，只有确认无待处理操作的已登录状态才能关闭。持久化的跳过记录不能绕过检查。根插槽同时覆盖恢复的对话和空会话，不修改共享设置协调器或智能体循环。

登录成功后，本次渲染器生命周期内不再自动弹出。后续账号操作由既有设置页和按需弹窗负责，重启或重新加载时再次检查。账号登录不会创建独立的模型 API Key。

## 考虑过的替代方案

设置引导插槽不会覆盖恢复的非空对话。根级遮罩覆盖每次启动，无需修改共享协调器。

## 后果

启动页要求账号登录。模型凭据和付费生产授权仍分别处理。

## 验证

账号组件测试覆盖未登录、曾跳过、操作中和已登录状态。原生账号的组合场景检查启动登录、浏览器等待和错误、重新加载，以及不丢失草稿的广场详情返回。真实生产登录和打包 Skill 执行需要独立实测。

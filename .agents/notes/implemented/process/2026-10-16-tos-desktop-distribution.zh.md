# Agent Note: 通过 TOS 发布客户端下载与更新

Status: implemented

[English](2026-10-16-tos-desktop-distribution.md) | 中文

## Problem

部分国内网络无法稳定访问 GitHub 安装包和更新清单，已发布的 0.1.18 客户端内置 GitHub 更新源。

## Decision

0.1.20 使用现有 HTTPS 资源域名和通用更新源。发布流程将通过哈希校验的文件上传到现有新加坡 TOS 桶的不可变版本目录，验证匿名分段访问后，最后写入禁止缓存的稳定版清单，其中安装包 URL 包含版本号。仅发布文件对象设为公开读，凭据保存在受保护的发布环境。手动同步工作流支持重试及补充手动发布的 Windows 安装包。上游构建取消或失败时不能发布；跳过可选的 Windows 签名不应阻止 Mac 发布。

## Alternatives considered

过期签名链接不能作为长期更新入口；公开整个桶会暴露无关资产；修改已签名的 0.1.18 包会使签名失效。以上方案均不采用。

## Consequences

无法访问 GitHub 的旧客户端需手动安装一次新版。未签名 Windows 仍需手动安装。原样同步保留安装包签名。测试覆盖损坏文件、错误版本和更新摘要、危险路径及缺失清单，实际通用更新源解析版本化 TOS ZIP。仍需国内地域下载验收，本地成功传输不代表所有用户网络。

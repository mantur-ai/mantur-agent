# Agent Note: 隔离推荐技能更新失败

Status: implemented

[English](2026-10-22-bundled-skill-update-isolation.md) | 中文

## 问题

三个随包推荐技能已从公开广场下架，详情请求返回 404。将首个请求失败视为整个首页目录失败，会隐藏可用的本地资源，并阻止后续推荐技能更新。

## 决策

广场插件分别返回可用的已校验身份和每个随包推荐技能的更新结果。元数据请求、下载或资源校验失败时记录技能名称、失败阶段和错误。随包身份仅在本地资源通过校验后提供；本地校验失败另行记录，并排除该身份。取消仍拒绝操作。线上检查失败绝不代表随包版本已被确认为当前发布版本。

客户端在重试期间保留可用条目，将更新失败与选择能力分开展示。精确版本与摘要引用仍通过现有校验器解析；重试不改写已保存草稿，也不删除已安装技能。压缩包摘要、受限解压、路径检查及不可变版本的原子发布仍为必需。不改变广场源或线上发布，不修改上游核心文件。

制片模式仅推荐 `mantur-drama-visual-studio`，中文 Tab 名为 `漫剧生产`，按钮及新插入引用的显示名为 `全自动漫剧生产线`。剧本和素材推荐保留原有配置。此限制只影响推荐入口，不删除随包资源、用户安装或草稿。

本决策取代[推荐技能自动更新](../architecture/2026-10-14-mantur-recommended-skill-updates.zh.md)中的全部推荐必须更新成功策略。

## 考虑过的替代方案

**一个线上请求失败就拒绝整个目录。** 技能下架或网络故障会继续隐藏无关的已校验技能。

**把本地可用报告为更新成功。** 本地校验只证明资源可用，不证明它是当前广场版本。分开记录结果保留了这一区别。

**删除已下架的本地技能或更改远端名称。** 下架不代表已校验本地资源失效，也不构成使用其他技能身份的授权。

## 影响

部分更新成功时仍可使用，失败更新保持可检查、可重试。响应字段与客户端消费者和测试同步变化，因此 Host 与客户端产物必须一起重建。线上检查失败后不搜索缓存并任意选择旧版本；候选是明确随包的身份。真实桌面和网络验收与针对性源码测试分开进行。

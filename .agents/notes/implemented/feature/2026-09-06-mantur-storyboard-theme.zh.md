# Agent Note: 漫途朱蓝分镜册主题

Status: implemented

[English](2026-09-06-mantur-storyboard-theme.md) | 中文

## 问题

漫途需要已确认的暖纸分镜册视觉，同时不能改变对话行为、遮挡完整目录标题或给图片预览染色。设计稿中的次要文字和状态颜色需要提高对比度，才能在侧栏用作小字。

## 决策

[漫途品牌插件](../../../../packages/client/ui-brand-mantur/README.zh.md)拥有可卸载、仅用于浅色外观的样式表。body 标记将配色限制在漫途；已有的 inert 应用根节点排除引导页。系统深色外观保持不变。小字使用比概念色块更深的暖灰、朱红、绿色和琥珀色。

已有框架提供装饰选择器。交付的 SVG 只绘制在上下 12 px 和右侧 16 px 的边缘区域，不接收指针事件，并在窗口小于 900 px 时隐藏。较窄的装饰区域让标记远离正文与控件，无需改变列布局。目录图片使用中性灰，视频留边保持深色。排版、完整标题与桌面五列配方网格维持已有行为。

## 考虑过的替代方案

**替换共享主题配色。** 这会改变非漫途组装与引导页的颜色，超出已确认范围。

**注册新的持久化主题选项。** 本次选择的是漫途浅色视觉，不是新的设置流程。保留浅色、深色和跟随系统选项可以避免修改存储设置。

**在整个对话区绘制插图。** 全页装饰与正文争夺注意力，也会改变图片颜色观感；仅在边缘装饰可保留干净的工作区。

## 影响

视觉仅作用于漫途，并随品牌插件卸载。深色模式保留已有中性配色，不增加未经确认的新设计。无密钥漫途浏览器场景检查浅深色切换、引导页排除、素材访问、中性预览、标题换行与五列布局；品牌单元测试检查样式表和标记卸载。

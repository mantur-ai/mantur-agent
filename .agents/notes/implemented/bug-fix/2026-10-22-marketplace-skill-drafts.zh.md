# Agent Note: 技能广场草稿

Status: implemented

[English](2026-10-22-marketplace-skill-drafts.md) | 中文

## Problem

未选择项目时，技能广场拒绝使用已安装技能。安装和使用按钮外观相同，安装状态不清晰。

## Decision

Mantur 导航插件追加现有结构化 `skill` 引用并返回对话。有选定项目时在该项目中新建会话，否则使用常驻的未分配草稿。现有首次发送策略负责准备项目和会话。草稿正文与附件保持不变，同一引用重复选择不重复插入。“已安装”标签和绿色使用按钮与中性的安装按钮区分。

## Alternatives considered

**移除项目检查并创建未分配会话。** 会话需要有效工作区归属；现有常驻草稿已经支持安全推迟创建。

**预填纯文本斜杠命令。** 结构化引用提供可移除的可见标签，复用已安装技能编解码器而不替换草稿正文。

## Consequences

没有核心文件或模型协议改动。安装仍由 Host 确认，选择不会提交回合。不同技能引用可以共存，与现有输入框快捷方式一致。控制器测试覆盖项目归属和输入锁定；真实组合的自动项目浏览器测试覆盖广场导航、草稿保留、刷新及显式首次发送，无需真实模型。

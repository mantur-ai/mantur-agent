# Agent Note：输入框技能入口

Status: implemented

[English](2026-09-11-composer-skill-entry.md) | 中文

## 问题

输入框重复提供侧栏技能广场功能，在用户预期的离线技能快捷入口处暴露了安装控件。

## 决策

输入框推荐栏只包含离线技能快捷入口。在线技能浏览与安装由侧栏技能广场提供。按用户要求移除“更多技能”按钮及其专用搜索、详情和安装弹窗；仅隐藏按钮会留下无法访问的安装控件。

## 考虑过的替代方案

仅隐藏按钮会保留无法访问的弹窗及其登录状态。移除专用弹窗使在线安装继续由技能广场负责。

## 影响

离线快捷入口无需登录；在线浏览与安装通过侧栏技能广场完成。

## 验证

创作引导与注册测试覆盖推荐技能插入、偏好变更、关闭引导和输入绑定。真实组合的浏览器场景记录不含“更多技能”的输入框，并保留草稿、附件及布局检查。技能广场的安装流程保留独立实现与测试。

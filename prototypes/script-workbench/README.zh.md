# 剧本工作台原型

[English](README.md) | 中文

## 概要

此隔离浏览器原型读取分集文件，在切集和收起时保留手动草稿，并针对原文件校验显式选段改稿。它不是已发布的 DSH 插件，也没有连接真实主 Agent。受控适配器只接受 `改为：替换文字`，不会调用模型、账号或算子。生产集成见[工作台集成决策](../../.agents/notes/implemented/feature/2026-09-09-script-workbench.zh.md)。

## 预览

在仓库根目录运行：

```sh
python3 prototypes/script-workbench/preview.py
```

打开输出的本地网址。服务监听随机本机端口，把两集合成剧本复制到私有临时项目；只提供白名单原型资源，并只写入这两个副本。停止服务后副本删除。页面初始为空态，必须明确点击才打开验收项目。无需安装仓库依赖或构建包。本地浏览器模块使用外盘既有依赖中的 Marked 16.4.2（MIT）和 DOMPurify 3.4.11（Apache-2.0 或 MPL-2.0），许可全文保留在 browser/；渲染子集排除活动 HTML、链接和远程媒体。

选择一集，编辑并保存，选中文字，填写 `改为：替换文字`，点击发送。展开验证工具，执行已排队请求。投递、执行、提交和读回分别记录状态。通过文件菜单查看最近改动或恢复前一版本。请求开始提交后不能取消。

本地项目选择器使用浏览器目录句柄，需要支持该功能的浏览器。递归列出非隐藏的 `.md`、`.txt` 和 `.fountain` 文件，把每个文件作为一集；不会猜测合并文档中的集数。此实验路径应使用可丢弃项目。草稿导出保留原扩展名。Markdown 默认以排版后的阅读模式打开，支持标题、引用、强调、列表和表格。需要选择改稿范围时切换到源码编辑。纯文本和 Fountain 保留原文预览。渲染不会改写源文件。

## 数据保护与限制

选区使用 UTF-16 偏移、选中文字、邻近上下文和整文件 SHA-256 版本。重复文本不会触发搜索或重新定位。草稿修订号或磁盘基准变化时，受控结果被拒绝。切集和收起保留草稿；读取文件变化时拒绝覆盖未保存草稿。恢复版本同样检查当前基准。草稿和撤销历史仅存内存；关闭或刷新页面会丢失，存在未保存正文时由浏览器提示。

验收服务串行处理自身写入。浏览器写入在打开独占浏览器写入器前，以及真正写入前各比较一次。这些机制都无法对任意外部程序提供原子比较写入；外部程序在最终比较与提交之间写入仍是生产阻碍。写后读回可以发现后续变化，但无法挽回已覆盖的外部编辑。不能把原型当成生产并发保证。

界面没有登录门禁。适配器和历史明确属于测试数据，不能替代真实 Agent。`dsh-bridge.mjs` 校验已有会话标识，调用注入的同会话 `conversation.send`；预览没有挂载它。生产请求必须走正常的已记录用户消息路径，文件完成状态独立于投递成功。生产写入入口还须在所有竞争写入路径上执行权限、版本匹配、请求取消、原子提交与恢复。

## 验证

```sh
node --test prototypes/script-workbench/tests/model.test.mjs
```

十三项受控测试针对私有真实文件副本通过：切集、手动保存与恢复、完整投递数据、第二处重复文本、并发草稿、外部变更、读取保护、取消、投递失败、读回冲突、错误会话拒绝、保存锁归属和提交阶段取消。未调用模型。测试没有启动 DSH Loader，也没有回放已发布 Session。

真实本地浏览器已验证空态、读取两集、第二处重复文本改稿、入队与完成状态区分、差异显示、切集、收起重开草稿保留、抑制 Agent 抢开和版本恢复。重构后的正文优先布局另行在浏览器检查。本机目录选择器权限与真实模型端到端尚未验证。预览服务和受控测试独立于当前运行客户端。

# Agent Note: 经所属窗口保存嵌入 Cut 的导出

Status: implemented

[English](2026-10-26-mantur-cut-embedded-export.md) | 中文

## 问题

打包 Cut 服务器绕过 Vite 的 HTML 转换，因此页面缺少会话导出目标。编辑器位于不同源的 iframe 内，浏览器禁止其打开文件选择器。回退到下载不能完成明确的文件选择操作。英文预览画质控件也会超出对话旁可用的宽度。

固定版本的浏览器 H.264 导出器会引入额外的 AAC 延迟。复现的五秒时间线中，提交给 AudioEncoder 的 PCM 与解码后的输出相差 44 ms；导入素材字节没有变化。独立视频片段通过浏览器媒体组件解码时，音频开头还会损失约 9 ms，这发生在最终 AAC 编码之前。[既有 AAC 收尾器](2026-09-07-mantur-cut-aac-timing.zh.md)负责服务端路径，不负责浏览器编码。

## 决策

受控的 [Cut 补丁](../../../../packages/client/ui-mantur-editing/adapters/mantur-cut-shutdown.patch)在嵌入服务器提供 HTML 时注入既有导出目录 grant。默认导出保留会话目录及既有的受校验服务端写入路径。[工作台](../../../../packages/client/ui-mantur-editing/src/client/Workbench.tsx)仅中继来自当前 iframe Window 及精确编辑器 origin 的文件请求。

隔离桌面 preload 在请求 Main 打开保存对话框前检查瞬时用户激活。[原生桥](../../../../apps/desktop/src/cut-export-bridge.ts)仅接受所属窗口的已认证主 frame。Main 保留原生选择的路径；编辑器只收到不透明 grant。有大小限制的顺序数据块写入目标旁的独占临时文件，成功完成后再替换目标。取消、替换、导航和失败会撤销或清理未完成操作。选择文件不会授予整目录或任意路径的写入 API。清理失败会保留文件所有者并阻止成功退出；重试可释放它。退出准备被中断后，当前 frame 可重新连接并选择新文件。同一活跃所有者的重复连接会在取消选择器时保留原选择。

浏览器部署把选择操作中继到支持的顶层文件选择器。不支持的浏览器保留默认目标或下载。取消会保留此前目标。预览画质控件在编辑器可用宽度内换行。

H.264 请求在浏览器能力或速度选择前使用既有本机渲染器和 PCM→AAC 收尾器，包括直接调用浏览器导出的入口。VP8/Opus 保留既有路由。服务端渲染时，普通视频片段使用既有独立服务端音频组件，其视频组件静音；预览渲染保持不变。不添加片段偏移或固定延迟。[来源 manifest（元数据清单）](../../../../apps/desktop/mantur-cut/source.json)固定重新生成的补丁摘要与结果 tree；上游及此前补丁层保持固定。

## 考虑过的替代方案

**保留 iframe 选择器并改善报错文案。** 跨源限制仍会阻止选择，默认目标也仍然缺失。

**把选定路径传给通用文件写入端点。** 这会给浏览器超过所选输出所需的权限。窗口持有的文件 grant 限制写入，并可随编辑器文档撤销。

**减去固定音频偏移，或在能力探测成功后保留浏览器路径。** 支持编解码器不代表预延迟元数据正确。固定偏移取决于编码器和采样率；既有服务端收尾器保留编码器的时序信息。

## 验证

桥接回归覆盖拒绝错误 origin 和窗口、缺少用户激活、取消、过期选择、顺序写入及清理。嵌入服务器检查覆盖实际提供的 HTML 和目标 grant。导出路由检查要求 H.264 使用本机渲染器，同时保留 VP8。打补丁后的编辑器通过 `npm run verify:audio-finalization` 运行真实 AAC 视频回归，覆盖软件与 VideoToolbox 渲染、分割片段、无声素材、静音和零音量。五秒回归工程具有 150 帧已验证红蓝画面，2.000 秒颜色切换，以及开头、分割点和颜色切换边界的非静音音频。冻结 composition 无法通过相同的 PCM 边界断言。仅凭流时长不能断言同步。原生对话框与窄窗布局仍需在各目标平台的候选包上完成 GUI 验收。

## 后果

即使系统支持浏览器编码，H.264 渲染也会使用本机媒体工具、浏览器子进程和临时 PCM/视频存储。此取舍优先保证经过验证的音频时序，而非浏览器速度启发式。原生文件授权仅在当前编辑器文档中有效；[恢复持久化决策](2026-10-27-mantur-native-export-recovery.zh.md) 定义导出任务存储如何保留该限制。[工作台决策](../feature/2026-09-06-mantur-local-editing-workbench.zh.md)继续负责会话和子进程所有权；本决策增加导出中继，不修改 Harness 核心或公共 MCP 工具。

# Agent Note: 带版本校验的剧本选段工作台

Status: proposed

[English](2026-09-09-script-workbench.md) | 中文

## Problem

作者需要阅读并手动编辑已生成的分集剧本，同时让现有 Agent 定点改稿。只有选中文字无法区分重复对白，也不能保护排队期间发生变化的草稿。单一工作台槽已有占用者，必须由拥有者决定显示内容，不能独立注册第二块面板。

## Proposal

保持一集一个文本文件。私有插件负责剧本发现、草稿修订、精确 UTF-16 选区和整文件版本。向当前作用域对话发送普通用户消息。文件写入在提交点校验请求与基准，保留恢复数据，只有文件读回后才发布完成。[隔离原型](../../../../prototypes/script-workbench/README.zh.md)用合成文件和受控适配器验证交互，没有挂载到 DSH profile。

与现有工作台拥有者协调最小的剧本/剪辑内容选择。复用可见性及实时打开抑制，保留独立的[详情面板生命周期](../../implemented/bug-fix/2026-07-29-web-details-session-lifecycle.zh.md)。新功能不取代该决策。限定范围的取代检查未发现已有剧本工作台决策。

## Alternatives considered

**复制完整剧本应用。** 原生应用集成及尚未核清的组件许可超出文本编辑需求，因此不采用。

**仅通过输入框发送选中文字。** 该数据无法安全处理重复文字和并发文件变更，因此不采用。

**把消息接收当成完成。** 排队消息没有逐条完成保证，可能在任何文件改动前失败或取消，因此不采用。

## Acceptance criteria

最终插件须通过隔离 profile 的 Loader 启动，回放记录的用户输入，并验证受控主 Agent 仅修改目标位置。覆盖并发手改/文件变化、持久恢复、取消、失败和面板收起。生产写入拥有者须在所有竞争写入路径执行校验。真实模型执行需要另行授权的凭据和费用。

## Risks

浏览器原型能发现旧基准，但无法原子排除任意外部文件写入。草稿和历史仅在当前页面生命周期内跨收起保留。会话发送适配器尚未挂载，不能证明真实主 Agent 执行。较新的剪辑基线中单一工作台槽已有占用者，拥有者提供内容选择前禁止注册竞争面板。

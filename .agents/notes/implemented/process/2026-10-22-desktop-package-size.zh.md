# Agent Note: 桌面发行调试符号与 DMG 压缩

Status: implemented

[English](2026-10-22-desktop-package-size.md) | 中文

## 问题

桌面编译器 map 用于源码级调试，但会占用安装包空间。DMG 压缩能够在不移除离线资源的前提下减小下载体积。

## 决策

桌面 [builder 配置](../../../../apps/desktop/package.json) 仅在复制时排除自身的 `lib/**/*.js.map` 与 `lib/**/*.d.ts.map`。`beforePack` hook 先在应用载荷之外归档 map、生成文件与磁盘源码字节，并记录版本、目标、路径和 SHA-256。备份失败会终止打包。构建者须从同一 checkout 重新构建，期间不得并行编辑：单独的源码快照无法证明过期编译产物来自该源码。Hook 不会修改或删除应用输入或已签名包。

[DMG 生成器](../../../../scripts/create-macos-dmg.ts) 使用 UDZO zlib level 9，再从压缩后字节生成 blockmap。对同一本地 0.1.11 卷的隔离转换测得默认级别为 795,638,073 字节，level 9 为 720,043,786 字节；转换耗时从 5.245 增至 32.118 秒。两份镜像均通过镜像校验，解压后的数据叉 hash 一致。该测量针对旧卷，不代表当前安装包。

## 考虑过的替代方案

**删除所有 map 或文档目录。** 依赖 map 可能存在不同消费者；名字类似文档的目录也可能包含离线资源。过滤范围限定为桌面编译器输出。

**在打包后裁剪 Cut。** Cut 构建信息对暂存的 Web、Remotion 与 compositor 内容记录摘要。删除前须单独验证其暂存过程和静态文件枚举；桌面过滤不改 Cut。

## 影响

调试符号目录须与发行产物另行保留。两个打包工作流分别上传受仓库访问权限约束的独立 90 天调试符号 artifact；发行组装不下载它们。发行负责人须在过期前归档。定向测试覆盖备份失败、源码路径逃逸拒绝及 builder 实际匹配。发布前仍须完成完整剪辑/导出验证及当前原生 macOS/Windows 打包。这些改动不代表已生成新安装包、签名、公开发布或生产部署。

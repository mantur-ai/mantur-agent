# Agent Note: 易读的聊天错误提示

Status: implemented

[English](2026-10-23-readable-chat-errors.md) | 中文

## Problem

提供方诊断包含技术英文和长标识符。错误码单独占据一列，使窄聊天面板中的错误说明空间不足。

## Decision

聊天渲染器按稳定错误码选择本地化处理建议，并把原始错误码和诊断放进默认折叠的原生详情。认证诊断仍隐藏。未知错误使用通用建议，不推断原因。错误行把剩余宽度留给正文，并允许长诊断换行。

此改动位于上游聊天渲染器，因为插件插槽无法覆盖其自有错误节点的内部布局。持久化事件、提供方错误和模型可见数据保持不变。

## Alternatives considered

直接翻译提供方消息会丢失诊断原文。根据英文片段猜测分类会依赖不稳定的提供方措辞。保留独立错误码列会降低窄布局的可读性。

## Consequences

已知错误提供本地化处理建议，技术详情仍可用于支持排查。新增错误码需要显式添加语言映射。自动检查覆盖分类、详情折叠和认证信息隐藏。窄桌面展示需要单独进行视觉验收。其他插件仍负责各自的错误视图。

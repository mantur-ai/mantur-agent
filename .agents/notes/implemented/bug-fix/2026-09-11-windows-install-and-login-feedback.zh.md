# Agent Note: Windows 安装与登录反馈

Status: implemented

[English](2026-09-11-windows-install-and-login-feedback.md) | 中文

## Problem

Windows 安装器跳过目录选择。打开 YAML 依赖文件关联，未关联 YAML 编辑器的电脑会提示安装软件。桌面登录路由不存在时只显示笼统错误。

## Decision

桌面 NSIS 包使用可选择目录的安装向导。原生文本编辑意图选择 Windows 记事本，包括经过转换的 WSL 路径；普通文件打开保留文件关联。高级配置文案说明首次文件为空的含义，并将其与账号登录区分。

创建授权请求的 HTTP 客户端将 404 归类为接口不可用，关闭响应体并保持凭据私密。其他操作保留远端授权请求错误。界面分别显示接口不可用、响应不兼容和网络失败，不更换配置的站点或认证协议。

## Alternatives considered

将正式客户端改连测试站会混淆环境。猜测并填写配置内容会掩盖服务器错误。因此均不采用。未签名 EXE 无法通过安装器参数获得发布者信任。

## Consequences

2026-09-11 正式站创建授权请求接口返回 404，macOS 安装包也复现协议错误。已有后端证据仅记录测试站部署 v2。正式站发布、真实浏览器授权和 Windows 签名仍是独立要求；这些客户端修正不能证明正式登录成功。

## Verification

聚焦的 HTTP、原生路径打开和组件测试覆盖接口不存在、远端授权请求错误、带引号的 Windows/WSL 路径和本地化操作。真实组装的浏览器场景记录接口不存在与响应不兼容状态，同时保留草稿。交付仍需原生 Windows 打包与系统级验证。

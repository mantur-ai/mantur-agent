# Agent Note: 关闭所属剪辑实例前确认保存完成

Status: implemented

[English](2026-09-08-mantur-editing-owned-shutdown.md) | 中文

## 问题

编辑器返回工具结果或 HTTP 响应时，附件、生成清理、工程防抖保存或占用释放可能仍在写入。此时关闭页面、连接或进程可能丢失已接受的工作。成功发送终止信号不能证明工作完成。

## 决策

[剪辑插件](../../../../packages/client/ui-mantur-editing/README.zh.md)提供结果缓存的 `stopForShutdown()`。它保留启动及运行实例，停止接收新的打开请求与 MCP 调用，并在编辑器排空前使用既有的 [MCP 执行排空](2026-09-07-mcp-owned-shutdown.zh.md)。此项前置工作完成前，Agent 上下文、信号、附件服务、HTTP 和浏览器页面保持可用。

编辑器通过现有认证的浏览器 poll/result 通道传递私有冻结与保存控制。浏览器先停止输入，再等待已接受的操作，因此这些操作仍能提交后端任务。后续后端截止拒绝新工作，等待原始请求及任务 Promise，包括响应之后的清理。最终保存覆盖挂载编辑器的防抖保存、草稿、运行账本和租约、生成结果确认及权威工程存储。编辑器确认排空前，浏览器注销必须完成占用释放的持久化。

编辑器确认后关闭原生 MCP 连接。真实 MCP GET SSE 处理器只在长连接结束后完成，因此不能放入客户端关闭前的保存排空。指定 MCP GET 和 DELETE 处理器的原始完成结果由独立的传输实例保留。开发及打包适配器在客户端关闭之后、HTTP 关闭之前等待该实例，并保留迟到的处理器错误。运行适配器随后关闭服务器；Host 等待所属子进程实际发出 `close`，包括管道结束。超时、取消、保留的写入错误或未知工作来源都会拒绝缓存结果，不强制终止。普通 fiber 卸载完成不构成成功证据。

第三层编辑器补丁在固定基础补丁和打包补丁之上承载该行为。不改依赖、音频收尾或公开 MCP 协议。集成在自己管理的启动位置记录具体媒体子进程，不扫描机器进程。所属 Remotion 包装保留浏览器关闭错误，并记录实际取得浏览器实例的行为。Remotion 4.0.509 没有提供受支持的进程与管道关闭证据，因此即使其关闭 Promise 成功，取得过浏览器仍会阻止退出成功。

桌面源码配置与资源清单对三层补丁程序使用格式版本 2。构建器检查每层补丁摘要及中间 Git 树，记录应用退出补丁后的最终树和全部三层源码补丁，并随完整源码配置改变分发标识。打包运行时在打开会话前拒绝旧的两层清单版本；旧资源证据不能验证此程序。

## 考虑过的替代方案

**宽限时间后强杀。** 这能确认终止，不能确认已接受的写入、渲染子孙进程或付费任务完成。

**同时冻结所有工作来源。** 已接受的浏览器操作可能在最初工具调用之后才提交任务，同时截止会拒绝这些已经接受的工作。

**新增 Agent 工具或重放失败修改。** 既有认证编辑器通道已经能传递生命周期控制；另一条剪辑通道或重放可能导致状态分歧与重复执行。

## 影响

这是严格且可测试的退出增量，不代表完整安装许可。使用过尚未接入排空的服务、缺少受支持证据的渲染器关闭，以及保留的回调错误仍然阻断安装。最初的真实浏览器检查保存了 150 帧纯色片段并释放浏览器占用，随后因先前语义索引请求失败而拒绝排空。后续修复在索引操作前向工程存储查询实际向量可用性；响应无效或查询失败仍然报错，已接受的修改继续纳入排空。扩展和模型目录的指定 GET 请求保留原始完成 Promise；安装与下载请求仍未接入退出管理。

定向证据覆盖 Host 实例与进程测试、无密钥录制 Web 工作流、实际原生 broker 截止与延迟占用释放、响应后仍未完成的 HTTP 回调、生成清理及保存失败，以及渲染关闭错误保留。HTTP 测试使用受控浏览器确认；后续全新真实浏览器检查保存一个 150 帧纯色片段、释放租约、完成排空，并在没有强制终止的情况下确认实际子进程关闭。这不能证明 AgentLoop 附件处理、渲染或已安装客户端完整退出。打包及独立 Host 组合仍需另行验收。

编辑器 `08950ed` 的真实 AgentLoop 与浏览器组合保存了两个纯色片段并释放租约后超时：保存排空等待 GET SSE，客户端关闭又等待保存排空。真实 SDK 回归复现该失败，并在修正顺序下检查迟到的保存、GET 和 DELETE 错误。适配器回归覆盖传输失败保留，以及 HTTP 关闭前完成传输等待。完整浏览器组合仍须独立验证新增量。

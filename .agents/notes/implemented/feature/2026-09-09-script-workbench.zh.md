# Agent Note: Versioned script selection workbench

Status: implemented

[English](2026-09-09-script-workbench.md) | 中文

## 问题

编剧需要阅读和手动编辑生成的分集，同时请求既有 Agent 定向改写。只有选中文字无法区分重复台词，也无法标识用户审阅的文件版本。多个插件独立注册单一工作台槽位，还会相互替换。

## 决策

[剧本插件](../../../../packages/client/ui-mantur-script/README.zh.md) 拥有共同工作台外框，为可选剪辑插件声明子槽。内容选择不改变可见性。同会话内切换和收起保留已挂载内容，布局沿用既有会话生命周期。卸载剪辑只移除其贡献。现场剪辑打开成功时通过外框回调选择该内容，同时保留既有的历史回放和手动关闭抑制。

每份剧本是项目内既有文本文件。阅读使用共用 Markdown 组件；准确选区来自 LF 规范化源码和 UTF-16 偏移。显式改写请求以普通持久用户消息进入既有作用域对话，包含路径、版本、原文片段和要求。发送不改变对话输入框，也不声称完成。选段改写工具校验版本及原文子串后，使用文件系统提供者的受保护写入和会话沙箱策略。手动保存与恢复使用同一个写入入口。缺少工作目录或路径跨出项目时明确失败。

注册时的 store 按会话和路径索引文档草稿。后续磁盘观察保留未保存草稿，并显示冲突。保存响应更新已保存基线，同时保留保存开始后继续输入的文字。运行转为空闲时请求文件刷新，不将其解释为某条排队消息的结果。本决策保留独立的[详情生命周期](../bug-fix/2026-07-29-web-details-session-lifecycle.zh.md)；限定范围的替代审计未发现更早的活跃剧本工作台决策。

## 考虑过的替代方案

**只发送选中文字。** 无法安全识别重复台词和过期文件，因此不采用。

**再注册一个根工作台。** 第二个单槽贡献会替换既有占用者，并丢失共同可见性所有权，因此不采用。

**创建另一个模型对话。** 剧本要求和工具结果属于用户既有会话历史，因此不采用。

## 影响

共同外框不增加模型供应商或登录要求。既有文件系统在原子发布时拥有版本检查，避免再造文件写入入口。精确偏移可以区分重复片段，冲突状态让手动文字保持可审阅。可选剪辑浏览器组合依赖共同外框，不再提供独立根占用者。

草稿和最后观察到的恢复点属于浏览器生命周期状态。页面重载恢复与持久多版本历史暂未实现。任意外部进程不共享文件系统的进程内逐目标锁。工作台编辑既有完整文件，不推断分集、不创建文件，也不映射渲染后 Markdown 的选区。

## 验证

包内测试覆盖真实文件的受版本保护写入、重复选段偏移、冲突保留、保存中继续输入、同会话发送、内容生命周期和注册释放。测试专用 Loader 组合在本地文件上执行真实工具，并记录工具 schema。浏览器组合使用普通漫途 profile 和隔离的合成项目文件。付费模型调用与应用打包不在本次验证范围内。

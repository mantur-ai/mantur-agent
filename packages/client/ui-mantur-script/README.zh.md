# @deepseek-ai/dsh-client-ui-mantur-script

[English](README.md) | 中文

## 概述

这个漫途插件拥有共同工作台外框，并编辑所选会话项目内既有的 `.md`、`.txt` 和 `.fountain` 文件。Markdown 默认通过共用渲染器进入阅读模式；显式切到源码编辑后可以准确选中文字。仅选中文字不会发送请求。

## 使用本包

漫途 bundle 通过明确的 `maxBytes` 和 `maxEntries` 上限挂载插件。点击对话边缘箭头打开工作台，浏览项目文件夹并打开一集文件。每个文件是一个可编辑文档，插件不根据标题推断分集。阅读和模式切换不会写文件。保存只允许替换最后观察到的文件版本。

先保存草稿，再选择片段并输入改写要求。“发送选段”通过捕获会话的既有 `conversation.send` 提交 JSON 用户消息，保留对话输入框和附件。消息包含路径、文件版本、UTF-16 起止偏移、选中文字和要求。接收消息表示已入队，不表示改稿成功。Agent 使用 `replace_script_selection` 检查版本和准确原文后，执行受版本保护的写入。插件不引入第二个 Agent、供应商、凭据或登录流程。

“检查文件更新”读取磁盘当前版本。观察到会话从运行变为空闲时也会请求读取，但这不代表某条消息已完成。磁盘新文字可以更新干净的视图；未保存草稿会保留，并明确显示冲突对比。版本变化使旧选区失效。“恢复上一版”执行另一次受版本保护的写入，有未保存或冲突草稿时禁用。

## 组合方式

插件是 `main.workbench` 与 `main.workbench.toggle` 的唯一注册者。声明的剪辑子槽接收可选的[剪辑插件](../ui-mantur-editing/README.zh.md)。只有剪辑插件已挂载时才显示剪辑标签。切换内容不改变面板可见性。首次激活后，同会话内切换标签或收起工作台都保留两个内容面板。切换会话时布局释放面板实例；注册时的 store 按会话和文件保留文档草稿，供再次挂载使用。卸载剪辑保留剧本外框；已选剪辑面板不可用时明确提示，不自动选择其他面板。

读取通过 `ctx.fs`，相对于所属 Agent 已记录的工作目录解析路径。项目外文件及指向项目外的符号链接都会被拒绝。UTF-8 读取受大小上限约束，并核对读取前后的版本；文字统一为 LF，供 textarea 偏移定位。保存、恢复和选段改写都使用 `replaceIfVersion` 及已挂载文件系统的会话沙箱策略。不发布 invariant companion，因为文件版本检查直接由文件系统写入执行，没有需要交叉核对的独立注册表。

## 模型体验

### 剧本选段改写

#### 模型看到什么

模型可见 `replace_script_selection` 工具 schema；仅在显式“发送选段”后，增加包含路径、版本、UTF-16 偏移、选中文字和改写要求的普通用户消息。调用和结果使用既有持久会话流程。不增加系统提示词分节。

#### Token 影响

工具 schema 进入请求头。每次发送选段将片段和请求字段加入对话历史；浏览、渲染、草稿编辑和手动保存不增加消息 token。

#### KV Cache 影响

挂载或移除工具改变工具 schema 请求前缀。显式选段追加到当前对话，不替换此前历史。

## 已知限制与待办工作

- 草稿和上一版对比仅在浏览器插件生命周期内保留，不提供页面重载恢复或持久多版本历史。最后观察到的版本是可用恢复点。任意外部进程不参与文件系统提供者的逐文件互斥锁。工作台不创建文件、不将单文档拆分为多集、不转换剧本格式，也不直接选择渲染后 Markdown 中的文字。既有 Agent 可以通过普通工具创建项目文件。文件夹按直接子项列出，不递归扫描；超出配置上限会明确报错。

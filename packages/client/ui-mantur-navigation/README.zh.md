# `@deepseek-ai/dsh-client-ui-mantur-navigation`

[English](README.md) | 中文

## 概述

这个插件为漫途侧栏增加“技能广场”和“配方广场”入口，并提供两个独立主页面。技能页面读取 Host 投影的 ManturHub 目录、打开详情、通过设备登录门禁安装，并展示安装与本地冲突状态。配方表示可替换用户内容并复刻效果的优秀验证案例，不是通用工作流模板。这个包还提供创作模式推荐与馒头仔助手引导，并把分组工作区标题替换为“项目”。官方 Web 组合不加载这个包，继续显示“工作区”。

<a id="use-this-package"></a>
## 使用方式

只通过 [`dsh-mantur-app`](../../bundle/mantur-app/README.zh.md) 组合这个包。所有者声明完成后，该包填充 `sidebar.navigation`、`sidebar.workspaces.heading` 和 `main.page`，再挂载浏览器安全的广场 Remote。打开技能页面会加载公开目录与本地安装标记；选择卡片会加载详情；登录后的安装请求通过 Host 写入文件，且只有 Host 确认后才更新可见卡片。已安装技能提供“使用技能”操作：它会在当前项目中新建默认命名的会话，打开该会话，并把 `/<skill-slug>` 写入尚未发送的输入框，让用户补充任务后再提交。页面选择存放在布局的临时 store 中，因此每次刷新都回到当前对话，不会把广场页面写入磁盘。

广场和创作引导中未登录的技能详情通过 Host 显式身份模式选择登录。桌面托管模式请求共享的[原生账号弹窗](../ui-mantur-account/README.zh.md)，独立模式使用 ManturHub 设备登录。身份查询失败或弹窗不可用时明确报错，不切换凭据来源。启动登录时暂时隐藏但保留来源详情。“返回创作”、Escape、跳过和成功都会恢复详情，不改变来源页面、项目、会话或完整草稿。成功只更新登录展示；安装、插入技能和发送仍需用户另行明确操作。

登录结束时，发起请求的详情把键盘焦点恢复到当前可用的主按钮。详情或会话变化、来源隐藏或卸载、其他活跃弹窗都会阻止焦点恢复。聚焦不会触发按钮操作。

配方页面通过服务端文本与分类筛选加载公开 ManturHub 目录，展示效果样片与分页，并在页面内打开包含可替换输入、提示词模板、模型、算子和权威复刻说明的详情。配方本身免费，算子执行采用实时报价，并在开始前由用户确认。“交给 Agent 复刻”会在当前项目中新建会话，并把 Hub 返回的 `agent_payload` 连同配方 slug 与 ManturHub 标识作为首条用户消息提交。仅当 ManturHub 发布来源 URL 时，这条消息才包含该地址。两个广场都使用 Host 本机配置选定的部署。

对话首页提供剧本创作、漫剧制作和素材生产。校验将旧 `editing` 偏好明确解析为 `production`，不改变工作台可见性；未知值会被拒绝。Host 持久化的 `ui-mantur-guide` 设置记住最近模式与明确关闭引导的选择，首次模式是 `script`。模式只改变推荐与固定引导：工作区、草稿、附件、已选技能、模型、权限和 Agent 身份保持不变。必填的 `recommendations` 配置按模式指定真实技能 slug 及顺序，只有当前 Host 目录返回的条目才会展示。缺失条目不展示，目录读取失败时提供重试。已安装快捷入口向当前输入框追加带标题的 `/skill` 引用并聚焦，不发送，也不重复插入已有引用。未安装技能显示简短安装确认，不展示描述和正文，仅在“安装后使用”成功后插入。关闭确认、切换会话或离开前往广场页面都会使待执行插入失效；页面跳转前即生效，返回也不会恢复。“更多技能”采用相同的当前输入框操作；广场独立的“使用”操作仍然新建会话。

推荐按钮及其插入引用使用相同的人工维护、本地化字典管理的短名，中文不超过四个汉字。悬停提示保留完整目录名称，引用 ID 与斜杠命令保留原 slug。每个配置中的推荐技能都需要维护短名映射，缺少映射时显示配置警告。“更多技能”保留列表完整标题，没有人工短名的技能插入时使用原目录标题，不截断或猜测名称。

首页工作区选择器保留在输入卡下方左对齐的页脚。权限选择器通过输入框附加区的子 slot，位于卡片内部、编辑器上方。Conversation 拥有权限状态与命令。DOM 顺序与键盘顺序一致；常驻编辑器、工作区控件、草稿转移和官方组合保留原有行为。

技能快捷按钮高 40px，边框为 1px。单行技能区保留触控板和键盘的原生滚动，不显示滚动条。仅当内容超过可用宽度时显示边缘箭头和渐隐提示；箭头每次滚动一个可视宽度，到达对应端点时禁用。

未选择项目时，桌面恢复原生未关联草稿，支持文字、图片和带标题的技能。“设置 → 通用”展示默认项目路径并打开原生目录选择器，修改只影响尚未预留的创建，不移动已有项目。首页页脚保留已有项目选择器，只在准备进行中或出现可处理错误时显示状态。首次发送通过 [mantur-projects](../../workspace/mantur-projects/README.zh.md) 准备项目、转移完整草稿，再由普通 Session input 提交。创建失败保留同一持久标识供重试，缺失原生持久化时明确阻止创建。

馒头仔使用固定本地化文案，以及随 Web 资源分发的已确认透明形象。各创作模式选择对应的 184×120 扒边图，图内 y=104 接触线对齐输入卡上沿。固定定位气泡位于角色右上方，不增加布局行；展开、关闭或切换模式时，推荐行和输入卡保持原位。模式标签下方的空隙不足以展示正文时，若标签右侧仍有至少 180px 宽度，气泡会移到标签旁边；否则正文在该空隙内滚动。两种位置均保留原字号、可见的关闭按钮，以及角色上方 8px 的间距。关闭按钮和 Escape 持久化关闭选择；关闭后切换模式不会重新展开。吉祥物及其引导只在对话首页渲染，进行中的聊天不显示两者。安装完成前切换了会话时，安装结果不会向任一对话插入引用。

-----

视口宽度小于 820px 时，首页推荐行额外预留 40px 高度，让标签下方的滚动正文保持可读。引导关闭时也保留相同空间，因此展开或关闭不会移动输入卡或工作区页脚。

用户明确选择模式且保存成功后，会发出 `mantur/creation-mode-selected`，重复选择当前模式也会通知。保存失败或设置恢复不会通知。剪辑工作台仅通过边界控件展开或收起，模式选择不改变其可见性。

<a id="understand-the-implementation"></a>
## 了解实现

<details>
<summary>实现细节——点击展开</summary>

浏览器插件安装导航、“项目”标题、根页面、创作模式、输入框布局、引导和通用设置 occupant，以及一个根作用域广场 controller。controller 分别管理技能与配方的目录和详情快照，生成的 Remote 让凭据与文件系统访问始终留在 Host。已完成的技能目录以及当前配方查询、页码和结果会在 controller 生命周期内保留于内存，因此重新进入页面会复用匹配状态，相同且尚未完成的配方请求也只发送一次。更改配方查询或页码会读取新数据，“重新加载”始终强制发起新请求，不会用缓存隐藏已知失败。刷新或重启客户端会创建没有持久目录的全新 controller。从广场启动技能时，它通过现有 controller 找到当前工作区、创建会话、经该会话的 input facade 写入斜杠命令，并在不提交的情况下打开会话。启动配方使用同一套工作区与会话 controller，但通过作用域化 Conversation 服务发送复刻请求。导航把选中的品牌化页面标识写入布局 store；根页面 occupant 渲染对应页面，并通过所有者操作关闭它。插件卸载或替换导致活跃根页面 occupant 卸载时，它也会清除自己的页面标识，让对话重新可见。卸载插件会让进行中的状态变更失效、清除登录轮询，并移除自己的 occupant 与本地化字典。

</details>

<a id="model-experience"></a>
## 模型体验

没有隐藏的模型上下文。选中的技能在用户提交前只是未发送的斜杠命令草稿。选中的配方则作为普通的首条持久用户消息提交。追溯文案使用当前界面语言，并包含标题、slug、ManturHub 标识以及 ManturHub 发布的可选来源 URL；其后的 `agent_payload` 保持发布原文。

#### KV Cache 影响

技能草稿在用户提交前不会贡献 provider token。配方消息会一次性贡献普通用户提示词 token。导航、目录卡片、详情元数据和其他界面文案不会进入模型请求。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- 原生桌面更新仅在进行中或可操作时显示于设置上方，收起侧栏时也保留入口。浏览器构建不暴露安装器。下载需要明确点击；重启确认和保存错误由原生控制器负责。在有可验证的最终 Host 检查点前，安装保持阻止。
- 配方发现与交接已可用。算子执行、报价确认和支付继续由 Agent 与 ManturHub 能力负责，不进入这个展示包。
- 技能页面支持安装，但刻意不提供强制覆盖或卸载。安装后被修改的受跟踪目录以及任何预先存在的未跟踪目录都需要人工处理。

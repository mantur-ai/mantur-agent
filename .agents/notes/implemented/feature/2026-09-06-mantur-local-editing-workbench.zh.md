# Agent Note: 从漫途打开本地剪辑工作台

Status: implemented

[English](2026-09-06-mantur-local-editing-workbench.md) | 中文

## Problem

漫途首页选择剪辑后，需要在对话旁打开完整时间线编辑器。详情栏限定于 Session 且宽度适合工具查看；`main.page` 会隐藏对话。现有两个位置都无法表达这个布局。

## Decision

在 `ui-layout` 中新增通用根插槽 `main.workbench` 和临时打开/关闭动作，保持对话在组件树中的位置稳定。可选的 `ui-mantur-editing` 插件管理编辑器视图、本地化控件、认证 Remote 和会话进程。漫途 bundle 包含默认禁用的配置行，显式指定编辑器源码和 Node。不修改 agent-loop，也不复制编辑器实现。

导航仅在设置接受用户明确选择后发出类型化的 `mantur/creation-mode-selected` 事件。重复选择仍通知；设置恢复和保存失败不通知。剪辑模式打开工作台，其他模式关闭工作台；卸载插件会释放监听和内嵌页面。模式按钮按对话栏宽度适配。素材、工程保存、提案审核和导出仍由上游编辑器负责。

Host 通过 Typert 解析当前 Agent，再读取其 Session 工作目录。每个会话使用 `<cwd>/剪辑/<session-id>/`，分开保存工程、素材和导出。会话拥有的子进程运行适配后的 OpenChatCut 0.2.14，提交为 `19cba6e1a70a3e589545ce02de975f6494c918f6`。既有 `dsh-mcp-client` 只挂载在该 Agent 作用域，bearer 保留于 Host。同一会话的并发打开共享启动，不同会话使用独立进程，卸载等待进程退出。先前实验工程保留在原路径。

Host 显式导入 MCP 插件的 `apply`、`Config`、`inject` 和 `name`。`apply` 的服务器名称预留保存在模块持有的 WeakMap 中，因此必须共享 peer 实例；配置与名称元数据是可安全重复安装的值。仅类型用途的 Host 引用保留为开发依赖，Typert 运行时则是普通依赖。

工作台订阅解析后的主题和语言。初始地址携带首次外观，后续通过校验源地址与窗口的消息切换，不导航页面。适配器修改界面变量及语言，不改动导出像素。包文件检查包含主题适配器、运行启动器和固定版本补丁。补丁将导入素材与默认导出位置映射到会话目录。

显示状态属于所选 Session，包括空白会话。没有会话和项目时显示明确提示。`ui-layout` 在界面操作前同步所选标识并保存已打开的标识。补丁移除内置对话、连接配置、重复设置、技能扩展、生成入口、品牌设计及上游推广，保留工具桥接与确认卡片，界面品牌为漫途Cut。

项目素材使用 Host 提供的 Agent 规范工作目录。本地编辑器接口经过请求校验，复用上游文件引用导入链路，供界面和 Agent 共用。请求路径及符号链接目标均限定在当前项目，排除剪辑输出和隐藏目录。重新定位通过编辑器命令更新原素材标识。兼容源文件通过引用记录提供媒体内容，删除引用记录保留原文件。

批准后的本地导入复用现有草稿执行器和检查点持久化。直接将素材写入真实工程会使当前导入会话自身的基础版本失效。手动模式的文件读取确认与草稿审阅分开；取消或真实工程的并发修改会拒绝候选草稿，不发布其中的素材。其他真实工程工具沿用既有执行路径。 终态编辑会话保留原始版本、已保存草稿及操作记录作为证据。首次检查点、后续草稿保存、审阅和终态关闭共用持久化队列。终态记录落盘后，先关闭内存中的编辑状态，再完成运行日志收尾，因此日志写入失败不会使已持久化的终态会话仍可编辑。读取器不会恢复终态会话、变基过期修改或重建缺失历史。适配补丁的固定来源及预期结果树记录在[包 README](../../../../packages/client/ui-mantur-editing/README.zh.md#understand-the-implementation)。

## Alternatives considered

现有详情插槽过窄且首页不可用；主页面会隐藏对话。复制编辑器状态会重复维护持久化和撤销逻辑。通用工作台插槽让这些职责保留在现有实现中。

## Verification

在固定上游的干净源码树应用受控补丁，结果精确匹配记录的编辑器源码树。终态持久化回归在独立写入与读取进程中使用生产 JSON 存储，覆盖检查点保留、保存失败、日志失败、首次及后续保存与取消并发，以及拒绝应用终态会话。导入回归保留本地文件批准和版本检查。这些检查不证明已部署、缺失的历史草稿已恢复，也不确定浏览器或 MCP 断连的原因。

适配器的 `verify:mantur-import-session` 检查使用真实项目素材 HTTP 接口和本地合成视频，覆盖连续文件与文件夹导入、草稿去重、文件读取前的批准及拒绝、检查点、审阅应用、并发修改拒绝、取消及原文件保持不变。既有编辑会话和 MCP 绑定检查继续生效。自然语言客户端从导入到导出的完整流程需要单独的验收证据。

定向组件与组合测试覆盖尚无 Session 时打开、保持对话节点、收起重开、重复选择、写入失败、无效地址、双语快照和卸载。Client 测试覆盖进程启动等待及失败、注入的主题读取和监听器卸载，以及拒绝格式错误的嵌入页面就绪消息。包级样式断言要求工作台及对话分隔线使用 0.5px 中性边框。源码组合测试显式替代生成的 Remote；构建组合验收使用生成实现。真实 `dsh --profile mantur` 组合可从首页剪辑标签打开已保存的编辑器工程。

项目素材检查覆盖目录排除、请求源校验、路径穿越和符号链接拒绝、引用文件的 HTTP 读取、重复导入、移动后重新定位及移除引用保留原文件。真实 MCP 导入在既有确认卡片批准后加入一张项目图片；界面导入另一张图片并跳过已引用图片。开发启动器将系统分配的端口保留到 Vite 重启配置，源码热更新后素材请求仍使用同一源地址。

Host 测试覆盖会话目录隔离、保留文件、拒绝穿越和链接、启动失败与超时、等待退出、合并并发打开及 Agent 作用域 MCP 挂载。Client 测试拒绝已切走会话的延迟启动结果，主题和语言切换保留当前页面。

真实编辑器导入了三段本地合成 MP4。公开 MCP 暂存三次裁剪和一次重排；在界面手动确认后应用四项操作。时间线从九秒变为六秒，单次撤销/重做可回退/恢复整批修改。在漫途中重新打开工程恢复了六秒时间线。浏览器导出生成 1920×1080 的 180 帧 H.264；完整解码及第 1、3、5 秒采样确认顺序为 C、A、B。未发起模型请求。

紧凑的宿主标题栏和有宽度上限的对话栏为编辑器腾出更多空间。展示补丁默认采用较窄的素材区、较低的时间线并收起属性面板；已保存的编辑器面板偏好仍然生效。用户仍可拖动面板分隔线，或切换属性面板。

## Upgrade check

桌面 dev 中的 Agent 调用了当前作用域的剪辑工具并读取活动工程。导入合成测试片段并导出六秒时间线后，会话导出目录生成了可完整解码的 1080p MP4。切走会话会隐藏工作台，返回时保留原有工程。会话顶部的剪辑入口可在页面刷新后重新打开工作台。

上游更新后重新应用补丁，运行剪辑与布局测试、Host 和 Client 构建及桌面首页模式流程。检查两个会话和两个工作目录、保留素材、Agent 工具作用域、修改确认、默认导出目录及进程退出，确认补丁不会恢复已删除的内置 Agent 配置。

## Consequences

集成需要准备好的本地编辑器源码和兼容的 Node。依赖及原生二进制的分发仍需另行处理。收起页面保留后台任务，卸载 Agent 或 Host 停止进程但不删除文件。

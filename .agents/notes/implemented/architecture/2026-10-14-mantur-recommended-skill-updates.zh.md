# Agent Note：推荐 Skill 自动更新

Status: implemented

[English](2026-10-14-mantur-recommended-skill-updates.md) | 中文

## 问题

线上发布新版本后，首页推荐仍选择客户端随包 Skill 版本。

## 决策

Mantur 广场插件在客户端启动和首页会话变化时，向当前部署检查随包允许名单中的技能。下载过程限制压缩包大小，校验发布的 SHA-256、完整文件清单及指令，在用户 Skill 发现目录之外原子发布不可变版本。不修改上游核心。

新选择捕获已校验的名称、版本和内容摘要。序列化与指令注入离线解析所选版本；更新不改写已有草稿引用。更新版本保留在应用专用存储中供旧引用使用，随包引用仍依赖对应应用资源。网络或校验失败显示重试，不替换为旧版本。已缓存版本号下重新发布不同内容会被拒绝。

## 考虑过的替代方案

**原地替换所选技能。** 会在选择后改变指令，破坏精确引用校验。

**更新用户技能目录。** 可能覆盖用户修改并使多个版本被发现。应用专用存储避免这两种影响。

## 影响

推荐技能可独立于客户端发布更新。用户安装的技能仍由显式安装操作管理。所有推荐检查成功后首页才提供新的选择。旧缓存版本占用磁盘且不自动清理。Windows 执行仍需平台验收；这些检查不代表完整付费生产流程通过。

## 验证

针对性测试覆盖升级、缓存复用、离线精确版本加载、取消、压缩包与指令拒绝、资源被修改及同版本重新发布。真实 Loader 与 Remote 浏览器用例覆盖下载和首页选择。可选正式环境测试比对四个推荐技能的当前详情版本，并安装真实公开包，不使用凭据或付费操作。

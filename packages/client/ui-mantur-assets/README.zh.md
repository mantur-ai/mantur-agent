# 漫途资产服务

此插件读取用户明确选择的漫途流水线报告，并分开保存提示词草稿、Agent 提案、实际请求字段和媒体观察结果。报告写回同时检查文件系统版本与 SHA-256 源指纹；替换前先写入待处理日志，恢复时不会猜测资产与媒体的绑定关系。

浏览器侧会等共享工作台声明资产槽后再接入，并可扫描用户明确选择的项目内候选目录，预览经文件签名校验的图片和视频。候选预览只表示待审核的本地文件，不会把空的报告绑定字段自动填上；Host 侧可独立验证真实报告读取与版本保护写回。

候选扫描只读取所选目录的直接子项，并继续受项目根目录约束；预览前会校验文件签名，再返回仅供当前 Session 使用的回环地址。

## 模型体验

模型只能使用 `propose_asset_prompts` 工具记录文本提案。工具不会生成媒体，也不会直接修改流水线报告；应用提案仍需用户明确触发 Host 操作。
